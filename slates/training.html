3 · How the network is trained (and then used)
Training: one step 
x0  = batch from dataset
t   = randint(1, T)
eps = randn_like(x0)
xt  = sqrt(ab[t])*x0 + sqrt(1-ab[t])*eps
loss = mse(model(xt, t), eps)
Sampling: the loop in view 2 
x = randn(shape)                 # pure noise
for t in T … 1:
  eps_hat = model(x, t)
  x0_hat  = (x - sqrt(1-ab[t])*eps_hat) / sqrt(ab[t])
  x = step toward x0_hat (+ fresh noise if DDPM)
return x

Predicting ε is the same as predicting x̂₀, and it is also the same as estimating the score ∇ log p(xₜ) = −ε̂ / √(1−ᾱₜ). The arrow field in view 2 is that score. It points from every noisy location back toward where the data lives.
