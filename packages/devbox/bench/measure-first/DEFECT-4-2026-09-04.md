# Defect 4: a published head nothing could find

Date: 2026-09-04. Status: closed. The write path is sound.

The decisive rerun (`kinu-devbox-bench-20260904142724`, commit `9a0fe0c7f`) failed both
candidate arms at the wake with `wake restored empty, expected attached`, after
each arm had published three generations whose envelopes stayed readable in the
bucket. Two later runs prove the published head survives, locally and deployed.
There is nothing to recover, so the held recovery is cancelled, not deferred.
A fallback that rebuilds a head from bucket bytes would hide the next lost
pointer instead of reporting it.

## Retired conditions, with the commits that retired them

The decisive empty wakes ran over stops that never stopped. The retained arm
rows carry `stopMs` with no outcome flag, so no archived bit proves those
stops completed, and a failed stop followed by a wake over the live box reads
exactly like a healthy recycle. Fixed by `6b217f201`
(`fix(driver): refuse wake when stop did not complete`), which fails the arm
before any wake over an unconfirmed stop.

Journal absence is now a precondition, not an assumption. Fixed by `20a20318e`
(`feat(driver): require an answering journal before the probe spends work`),
after its transport defect was fixed in `1c453be01` (staged probe bytes run
from a file instead of shell-quoted `bun -e`). A missing journal aborts before
any write; a failed later tick aborts before stop and wake.

The stop tolerates a daemon row it cannot kill, as its sibling always did.
Fixed by `66aa6f501`. Read-only analysis showed the release pass kills the
daemon tolerantly while `stopJournal` re-killed the lingering row fatally
seconds later, and the local fake masked it because its kill deletes the row.

Diagnostics that made the comparisons possible: `4df414737` (control dump),
`3a701a9c9` (incident reasons), `ab487275b` with `c8d14b606` (fixture routes
`GET /candidate` control field and `GET /incidents`).

## Inference, labeled as inference

The decisive empty wake is best explained by the retired conditions above:
unverified stops measured as recycles by a driver that has since learned to
check, against a journal whose absence is now a precondition. That explanation
stays inference. No archived row from that run can promote it further: its
incident reasons were kept as totals only, and its stop records carry no
outcome flags.
