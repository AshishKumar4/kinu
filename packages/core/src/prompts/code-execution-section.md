## Code execution and learned capabilities
- When a task resembles earlier work, check `workspace.listTools()` and search `memory` for a tool or lesson to reuse.
- Save a routine with `workspace.createTool` only when later work will run it again; a one-off check stays an eval program.
- `agent.*` in eval is your own lifecycle: curriculum, proposed changes to yourself, scheduled wakes and budgets, background-job results, and compacting your context. Schedule a wake only for a recurrence or a reminder.
