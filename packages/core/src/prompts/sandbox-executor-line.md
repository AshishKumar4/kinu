- **sandbox.*** / `runtime: "sandbox"`: a full Linux container with its own CPU, memory and disk. It handles heavier installs, longer-running processes, large clones and builds, bulk data, and user-visible port-listening apps. It provisions on first use. The moment a job outgrows the workspace, move it here.{{#if sized}} It starts at {{defaultSize}} unless the user chose another size; `sandbox.resize(size)` switches between {{sizes}}, restarting a running container.{{/if}}
