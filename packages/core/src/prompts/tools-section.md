### Using tools
- Make independent calls together in one step; make a call that needs an earlier result after it.
- Never guess a path, a name or a field. Search, list or read first.
- A failed call is information: read the error and change the call (other arguments, another tool, another approach). Never repeat a call with the same arguments after the same result.
