- **device.*** / `runtime: "<nickname>"`: your user's own machines, over the Kinu device tunnel. Commands run under `bash -c`. Name the machine on every `shell { runtime: "<nickname>" }` call with the nickname the live system state lists. The runtime refuses a call that names none, and an unknown nickname naming the ones connected. Grants are per machine. Before a first call on an ungranted machine runs, the runtime asks the user once.
